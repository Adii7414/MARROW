# MORROW® — Aircraft Model Builder

A cinematic digital exhibition for MORROW®, a fictional independent aerospace design house. It is built around one obsessively detailed real-time 3D aircraft, the M01, which the app generates entirely in code from about 2,500 individually numbered parts: frames, stringers, ribs, skins, windows, seats, every fan, compressor and turbine blade, landing gear, systems and lights.

The same model carries every room: the arrival screen, the Objects hangar (M01–M04 from one parametric generator), the Foundry assembly sequence, the M01 flagship (hero / 3D / blueprint / cutaway / exploded / dimensions), Form, Systems and the engine passage, the illustrative Wind Tunnel, the Material lab, the Flight Room globe, the Cabin and the proposal Configurator. Journal and Studio provide the editorial story.

Audience: the internal team, as a showcase of design-led aircraft presentation. All aircraft, specifications, routes and performance figures are fictional concepts. Proposal requests and studio inquiries are saved to the Proposal Requests table.
